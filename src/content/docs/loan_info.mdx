The LoanInfo API allows you to get a consolidated view of a mortgage loan.

After you processed your document with our API, you can both inspect the extracted data for each document
or you can get `LoanInfo` for the entire loan.

:::note[Triangulation of LoanInfo]
We automatically triangulate the LoanInfo from each document in the loan, so you don't need to call an API to get the LoanInfo.
:::
