# Areal API Documentation

This documentation aims to provide you with a high-level understanding of the Areal project.
Each section explains a specific component / product of Areal

For techinal details see [API-Documentation](https://dev-api.v2.areal.ai/api/v2/docs#)

Suggested reading order:

1. [Authentication](accounts/auth.md): How to authenticate and authorize users to access the API.
2. [Processing](processing/index.md): How to process documents and extract structured data.
4. [Gateways](gateways/index.md): How to integrate with external LOS services such as Encompass and RamQuest.
5. [CDBalancer](cdbalancer/index.md): How to balance Closing Disclosure documents
6. [Copilot](copilot/index.md): How to automate tasks and workflows using AI.
